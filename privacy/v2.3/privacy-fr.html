Politique de confidentialité de SixFour Échecs

Dernière mise à jour : 15 février 2026

Éditeur : ADOUANI SAS

Application : SixFour Échecs

Vue d’ensemble

SixFour Échecs est pensé pour fonctionner en priorité en local. Par défaut, les données de partie restent sur votre appareil. Nous n’utilisons pas de SDK publicitaire ni de SDK de réseaux sociaux.

Aucun identifiant publicitaire

Données collectées

Nous ne collectons pas de données personnelles pour le jeu hors ligne.

Fonctionnalités optionnelles

  • L’historique local des parties et les préférences sont stockés sur votre appareil.
  • Le mode Maître peut envoyer uniquement la position d’échecs courante au format FEN vers des services d’analyse externes.
  • L’analytique et le crash reporting ne peuvent être activés qu’avec votre consentement dans l’application.

Services tiers

  • Lichess Cloud Eval : https://lichess.org/api/cloud-eval
  • Stockfish Online : https://stockfish.online/api/s/v2.php

Stockage local

L’historique des parties, les paramètres et les snapshots restent sur l’appareil, sauf si vous désinstallez l’application ou les supprimez depuis l’application.
