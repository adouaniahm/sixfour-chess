# Code of Conduct

SixFour follows a simple rule in every contribution:
**respect, inclusion, and professionalism**.

## Expected behavior

- Use a courteous, professional tone.
- Be supportive and constructive, especially during disagreements.
- Focus on code and architecture.
- Clearly call out trade-offs and known limitations.

## Unacceptable behavior

- Harassment, abuse, insults, discrimination, or exclusion.
- Offensive or threatening behavior.
- Spam, trolling, or repetitive off-topic comments.
- Sharing private project details or sensitive user data.

## Reporting

If you encounter a problem, open an issue with:

- what happened,
- where it happened,
- when it happened,
- any people involved (when known).

The project team will review and triage by severity and act.
