# Security Policy

If you suspect a security issue, report it privately. Please do not open a public issue for a suspected vulnerability.

## Reporting

- Email `adouani.sas@gmail.com` with:
  - a clear risk summary,
  - steps to reproduce,
  - potential impact,
  - app version and environment.

The maintainer will acknowledge the report and coordinate a fix before any public disclosure. Public issues are appropriate only after the issue has been fixed or when explicitly requested by the maintainer.

## Contact

Email: `adouani.sas@gmail.com`

## Reporting best practices

- Do not include real personal data.
- Do not run aggressive production probes.
- Use minimal proof-of-concept reproductions.

Reports are triaged by severity and responded to with a mitigation plan.
